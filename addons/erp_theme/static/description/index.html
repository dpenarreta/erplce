ERP Theme

Tema visual ERP LCE para el cliente web de Odoo 18

  • Menú lateral negro con las aplicaciones del usuario (respeta los grupos), sus íconos y submenús desplegables; se puede contraer a solo íconos.
  • Barra superior clara sin cuadrícula de aplicaciones ni menús de sección.
  • En pantallas de menos de 992 px el menú se abre como panel superpuesto desde el botón de menú.
  • Contenido en tarjetas blancas sobre fondo gris claro y tipografía Inter (SIL Open Font License 1.1, incluida en static/fonts/).

La marca (colores, logo, login) sigue en erp_branding: al desinstalar este módulo se vuelve a la disposición estándar sin perder la marca.
