ERP Branding

Marca ERP LCE para el cliente web de Odoo 18

  • Nombre de marca configurable con el parámetro de sistema erp_branding.name (por defecto ERP LCE): título de la pestaña del navegador, pantalla de login y nombre de la aplicación web (PWA).
  • Logo y favicon propios (placeholder con las iniciales LCE).
  • Login sin el enlace «Powered by Odoo».
  • Paleta institucional de LAARCOURIER EXPRESS S.A.: amarillo #FCE200, negro #000000 y gris #E1E1E1, con contraste WCAG 2.1 AA.

Para sustituir el logo provisional basta con reemplazar static/img/logo.svg, static/img/favicon.svg y los iconos PNG/ICO de static/img/ manteniendo sus nombres.
